# Phở Rush

Giao phở nóng hổi qua một con phố và con ngõ Hà Nội bằng robot giao hàng. Chơi ngay trên trình duyệt (điện thoại hoặc máy tính):
https://dusamavn.github.io/pho-rush/

- Điện thoại: kéo cần lái ở dưới màn hình, thả ra để dừng.
- Máy tính: WASD hoặc phím mũi tên.

Đây là bản build tĩnh (đã biên dịch) của chế độ chơi Phở Rush trong StreetSense Adventure. Nguồn tài sản: [credits.html](credits.html).
